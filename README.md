# Construct

**Construct is sunset.**

I built Construct to keep a project’s context and constraints together for the AI tools I use, and to help coordinate work. It brought together skills and workflows around the work I was trying to get done.

I’ve decided to sunset Construct and put that effort into getting more out of the tools I already use. I’m testing Hermes alongside Claude Code and Codex, with Obsidian for the knowledge I want to keep and Raycast to make the day-to-day easier. That setup is still taking shape.
