# Construct cutover records (2026-09-20)

These files are the durable working state for the native-work cutover.
They are engineering records, not user documentation and not a second
tracker. The native ledger becomes the ready queue once it exists; until
then `PLAN.md` is the one bootstrap plan.

- [`MANDATE.md`](MANDATE.md) — frozen assignment, verbatim.
- [`BASELINE.md`](BASELINE.md) — checkout, runtime, dirty-worktree boundary.
- [`FINDINGS.md`](FINDINGS.md) — A01–A16 dispositions and evidence.
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — chosen direction, rejected alternatives, risks.
- [`PLAN.md`](PLAN.md) — bootstrap execution plan until the native ledger owns it.
- [`SOURCES.md`](SOURCES.md) — primary-source register for implementation questions.
- [`DELETION.md`](DELETION.md) — retain / repair / remove inventory.
- [`VERIFICATION.md`](VERIFICATION.md) — final evidence report (filled at close).
