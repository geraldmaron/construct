# Installation

Choose the install path that matches your project ecosystem.

- [Local (npm)](./local.md) — global install for individual developers
- [Bootstrap shim](./bootstrap-shim.md) — non-Node projects, runs Construct via `.construct/run.mjs` without a global install
- [Devcontainer](./devcontainer.md) — VS Code / GitHub Codespaces teams using `construct init --devcontainer`
