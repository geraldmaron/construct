## Execution order and acceptance envelope

1. **Retrieval and evidence identity:** fix full-history search/continuation; expose previous revisions and versioned packets; finish scoped source observation and schema mapping contracts with deterministic public tests.
2. **Substantive verification and skills:** typed claim-support checks, executable verifier binding, method result contracts and digest-bound qualification. Known-bad cases must be rejected before positive evidence is collected.
3. **Fresh consumer matrix:** repeatable packed-source fixture runner across API/MCP/local, multiple domains and ordinary prompts; test actual bounded traversal and source correction, then independent withheld outcome scoring. Run current installed authorized hosts and a host-native baseline.
4. **Durable operation:** disposable clock/worker/sink, recovery at multiple interruption points, exact receipt delivery and no duplicate effect; verify denial/expiry/budget/pending-decision states.
5. **Release and closeout:** canonical digest-bound evidence, all attempts and denominators, required full repository gates, independent counterexample recheck and native acceptance reconciliation. No broad item closes solely because a document states its limitation.

Predetermined deterministic thresholds: all contract negative cases rejected; zero unauthorized reads/writes; no stale or wrong-subject receipt accepted; no false deletion under partial coverage; exact native ownership and attempt fencing. Source fixtures must retrieve all labeled material reachable within declared permission/budget; each inaccessible or budget-excluded material item must be explicit. Every promised artifact and delivery must exist with matching digest. Independent substantive score requires all critical correctness/uncertainty/evidence criteria, with zero fabricated facts or silently merged contradictions. Failures and reruns remain in denominators. These gates establish their finite cases, not a universal probability estimate.

The target host set remains the product's named set. An unavailable cell is explicitly blocked/experimental; it is never a pass or silently removed. Installed CLI inventory currently includes Codex, Claude Code, Cursor, VS Code and OpenCode; Bob has not been found. Authentication, callable interfaces and real outcomes must be measured before drawing further conclusions.
