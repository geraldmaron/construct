# Multi-agent coordination

Records for making several agent sessions, from any MCP host, work safely in one Construct project at the same time.

| File | What it holds |
|---|---|
| [PLAN.md](PLAN.md) | The approved plan: outcome, decisions, the condensed gap register, the phased roadmap, and the verification plan. Start here. |
| [DESIGN.md](DESIGN.md) | The full recommended design with its challenge record, per-host delivery matrix, and phase-by-phase finding lists and acceptance criteria. |
| [FINDINGS.md](FINDINGS.md) | Every verified audit finding by id, with the verifier's verdict and severity. PLAN.md and DESIGN.md cite these ids. |
| [DELEGATION-VERIFICATION.md](DELEGATION-VERIFICATION.md) | The bounded delegation checkpoint of 2026-09-27: the implementation and synthetic gates that pass, the live three-tool verification that has not been done, and the release gates still open. |

Progress lives in the native work ledger (`construct work`), one item per phase slice.
