# Skill use ledger

The pre-registered instrument for the skills wedge (tracker: the pilot-skill
bead carries the test verbatim). One line per real invocation of a shipped
skill. The claim under test: the skill makes its user measurably better at
evidence-work, wherever that work happens.

**Refuted if** ten real invocations produce zero gate-changed-outcome lines —
the value was the model's baseline, not the encoded method. **Separately
refuted if** ten invocations are not reached within about four weeks of
install — that falsifies triggering or distribution, not the method, and the
fix is the description field or the distribution path.

A "yes" in the last column requires the receipt: which gate, and what changed.
An honest "no" is a data point, not a failure to hide.
