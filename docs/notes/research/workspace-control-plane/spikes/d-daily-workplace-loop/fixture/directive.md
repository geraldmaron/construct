# Nimbus daily workplace loop — standing directive (FIXTURE)

_Issued by fictional VP Product "Priya Nair", 2026-04-01._

## Mission

Run once per day. Read the current strategy, objectives, and the day's
signals from engineering (GitHub), the backlog (Jira-style), and
conversation (Slack/Confluence-style notes). Surface what changed, what's
stale, what conflicts with stated strategy or stated status, and what a TPM
would flag in a standup if a human were doing this by hand.

## Scope

- Read-only over all fixture sources.
- May draft recommendations, briefs, and backlog-item proposals.
- May maintain its own internal signal/graph state to avoid re-reporting the
  same finding every day.

## Explicit non-goals

- Not a replacement for the humans who own each objective — it recommends,
  it does not decide.
- Not a general project-management tool; it only reasons over what's in the
  fixture sources plus its own run history.

See `authority-policy.md` in this same directory for the specific
allow/deny list governing anything that would leave a proposal and become a
real external write.
