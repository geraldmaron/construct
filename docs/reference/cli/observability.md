# Observability

| Command | What it does |
|---|---|
| `construct cost` | Token usage and cost breakdown |
| `construct efficiency` | Read efficiency metrics |
| `construct evals` | Evaluator catalog |
| `construct llm-judge` | LLM-as-judge evaluations |
| `construct optimize` | Prompt optimization |
| `construct review` | Agent performance review |

## construct cost

Token usage and cost breakdown

**Usage**

```bash
construct cost [--days=N]
```

## construct efficiency

Read efficiency metrics

**Usage**

```bash
construct efficiency
```

## construct evals

Evaluator catalog

**Usage**

```bash
construct evals
```

## construct llm-judge

LLM-as-judge evaluations

**Usage**

```bash
construct llm-judge
```

## construct optimize

Prompt optimization

**Usage**

```bash
construct optimize <agent>
```

## construct review

Agent performance review

**Usage**

```bash
construct review [--days=N]
```
