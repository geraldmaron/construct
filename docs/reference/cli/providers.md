# Providers

|---|---|

## construct provider

List, inspect, and test data-source providers (GitHub, Atlassian Jira, Atlassian Confluence, Slack, Salesforce, custom plugins).

**Usage**

```bash
construct provider <list|info|test|plugins> [<id>] [<package>] [--global]
```
