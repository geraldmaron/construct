# T-24417: Hydrator: DrySource   Helm support

> Origin: https://github.com/argoproj/argo-cd/issues/24417 (verbatim base; see PROVENANCE.md for edits)

# Summary

Currently it not possible to point DrySource at Chart contained in a Helm Repository. 

# Motivation

Existing workflows use Helm charts to provide things like cert manager. We also published our in house services to a helm repository before we deploy via argocd.
To use the Hydrator would mean switching to helm dependencies which makes it difficult to use with ApplicationSets to control the chart version across environments.

# Proposal

Add the ability to use helm charts as a DrySource. Currently the only thing missing is `Chart` from the spec of DrySource.

Other Work required for this to work would be able to set the SyncSource and HydrateTo to different repository #22719 

There are also other helm issues outstanding #24228 #23396 which may also be relevant to this issue.
