# T-27846: new metrics to be added for progressive sync

> Origin: https://github.com/argoproj/argo-cd/issues/27846 (verbatim base; see PROVENANCE.md for edits)

# Summary

Add appset metrics related to progressive sync

# Motivation

https://github.com/argoproj/argo-cd/pull/27467#discussion_r3171153420 
# Proposal

As pointed out in the comment, getting a wide-eye view of progressive sync is difficult. 

(extracted from the above comment), proposal is to have metrics or logs that could be added to monitor the performance of the ApplicationController progressive sync that could help to answer questions like:

1. How much time did it take to start triggering the progressive sync vs the time it detected it.
2. How much time did it take to complete step X of the sync
3. How much Application refresh were caused by the ApplicationSet.
4. My sync is not starting, why/which Applications is it waiting for?
