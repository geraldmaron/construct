# T-28927: Promote Progressive Sync to Stable

> Origin: https://github.com/argoproj/argo-cd/issues/28927 (verbatim base; see PROVENANCE.md for edits)

# Summary

Progressive Sync feature is beta since v3.3. This issue aims to capture issues to be resolved before promoting Progressive Sync to Stable

# Motivation

Per the definition of [feature status](https://github.com/argoproj/argoproj/blob/main/community/feature-status.md) for argoproj:
Stable features are tested and validated with various use cases, are considered mature, and are expected to be backwards compatible. Issues will be tracked as bugs, and depending on the impact, a patch with the fix might be released.

With key execution issues being addressed (out-of-order sync blocker resolved in [#27467](https://github.com/argoproj/argo-cd/pull/27467) for v3.6), we are defining the remaining scope required for maturity
