# Construct

Construct is available in this project.

## How to work

- Use Construct MCP tools directly from this session.
- Stay in the current interactive agent environment unless the user or project
  explicitly requests another executor.
- Do not invoke `construct work`.
- Do not start another general-purpose coding agent merely because it is
  installed or authenticated.
- Use Construct to record and coordinate the user's requested outcome.
- Perform assigned interactive work in this session.
- Submit completed work through Construct.
- Surface approvals and decisions conversationally.
- Use relevant project sources and method skills when they materially improve
  the work.

## Stand down

If the user is not asking Construct to record, coordinate, claim, submit, or
decide, do not interpose. Applying nothing is a correct outcome.
