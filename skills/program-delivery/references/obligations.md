# Obligations: Program delivery

What a deliverable this pack owns must carry, as checkable slots. Empty slots are named as empty, never filled with invention.

- **Claim consistency.** dates, dependencies, and allocations that cannot all hold, each with the two sources that disagree
- **Critical path.** the chain of dependencies that sets the end date, with the constrained resource named
- **Capacity.** a range derived from explicit assumptions (people, availability, skills, operational load, history), never a throughput figure alone
- **Risks with owners.** each risk names its owner, its trigger, and what is decided now versus later
- **Status honesty.** what happened, what did not, what slipped, and what is decided; no color without the sentence behind it
- **Decision rights.** who decides each open call, per the constitution
