# Sources: Security and privacy

Doctrine this pack rests on. Each entry names what it is used for and when it was last reviewed. Each entry was opened on 2026-10-17 and says what was confirmed; a finding that leans on a specific clause or number still opens that clause. Time-sensitive doctrine carries a review-due date.

- OWASP Application Security Verification Standard (https://owasp.org/www-project-application-security-verification-standard/). Used for: the verification requirements a review checks against. Reviewed: 2026-09-02, review due 2027-03. Opened 2026-10-17: the project page names 5.0.0 as the latest stable release and describes the standard as a basis for testing web application security controls and a requirements list for developers.
- OWASP Top 10 (https://owasp.org/www-project-top-ten/). Used for: the exposure classes named in findings. Reviewed: 2026-09-02, review due 2027-03. Opened 2026-10-17: the page says the most current release is the OWASP Top 10 2025; the category list lives at owasp.org/Top10/2025/ and was not opened.
- NIST Secure Software Development Framework, SP 800-218 (https://csrc.nist.gov/projects/ssdf). Used for: practices a change must not regress. Reviewed: 2026-09-02, review due 2027-03. Opened 2026-10-17: the project page names SSDF version 1.1 in SP 800-218 as final, and notes SP 800-218A, a generative-AI community profile that augments it.
- Microsoft STRIDE threat model categories (https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool-threats). Used for: the threat categories walked per component and flow. Reviewed: 2026-09-02; stable. Opened 2026-10-17: Microsoft's Threat Modeling Tool page defines the six STRIDE categories: spoofing, tampering, repudiation, information disclosure, denial of service, and elevation of privilege.
- Regulation (EU) 2016/679 (GDPR), Articles 5 and 25 (https://eur-lex.europa.eu/eli/reg/2016/679/oj). Used for: the principles (minimization, purpose limitation, storage limitation) and privacy by design; whether they apply is a qualified judgment. Reviewed: 2026-09-02, review due 2027-03. Opened 2026-10-17: Article 5 "Principles relating to processing of personal data" names purpose limitation and data minimisation and sets the storage limit in 5(1)(e); Article 25 is "Data protection by design and by default".
- ISO/IEC 27001:2022 control set (https://www.iso.org/standard/27001). Used for: the control vocabulary a finding names. Reviewed: 2026-09-02, review due 2027-09. Opened 2026-10-17: the landing page confirms ISO/IEC 27001:2022, Edition 3, published 2022-10, with one amendment (Amd 1:2024, climate action changes); the control text itself is sold and was not opened.
